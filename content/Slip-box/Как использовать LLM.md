Для каких задач могут быть полезны LLM:
- составление нужных команд bash
- проверка орфографии, пунктуации в текстах
- throwaway code
- проверка идиоматичности кода 
- изучение новых для меня, хорошо документированных областей знаний (мне, например, помогло с Битриксом)
- summary больших статей, как в Readwise Reader
- написание тестов к "чистым" функциям
- рекомендации по устранению ошибок на основе анализа traceback
- когда сервисы вроде Logfire формируют запросы на своём диалекте SQL на основе описания от пользователя – нет нужды изучать особенности запросов каждого сервиса, чтобы быстро получить результат
