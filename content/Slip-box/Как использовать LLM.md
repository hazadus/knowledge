Для каких задач могут быть полезны LLM:
- составление нужных команд bash
- проверка орфографии, пунктуации в текстах
- throwaway code
- проверка идиоматичности кода 
- изучение новых для меня, хорошо документированных областей знаний (мне, например, помогло с Битриксом)
- summary больших статей, как в Readwise Reader
