## Highlights
- `flush` в SQLAlchemy отправляет изменения в базу данных без их окончательной фиксации, то есть без выполнения коммита. Это полезно, когда нужно сгенерировать данные, такие как идентификаторы (например, user.id), чтобы использовать их до фактического сохранения данных в базе. При этом сама транзакция остаётся открытой, и окончательное сохранение происходит позже, при вызове commit. ([View Highlight](https://read.readwise.io/read/01je8djbr691sqacnm8fpgfw4c))

- Для массового добавления данных в SQLAlchemy существует удобный метод add_all. Он работает аналогично методу add, но принимает на вход список экземпляров (инстансов). С его помощью мы можем добавить сразу несколько записей за одну операцию. Давайте рассмотрим пример, где добавим пять пользователей с использованием этого метода. ([View Highlight](https://read.readwise.io/read/01je8dkg0dww9edrx06v232dr8))
